# ВелоПрокат — информационная система «Прокат велосипедов»

Учебный проект: Django 6.1 + PostgreSQL. Этапы: 1 — база данных и ER-диаграмма (`docs/er-diagram.pdf`),
2 — приложение с ролями, каталогом, оформлением и просмотром прокатов.

## Запуск

Нужны Python 3.12+ и PostgreSQL.

```bash
python -m venv venv
venv\Scripts\activate                # Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env               # и заполнить SECRET_KEY, DB_PASSWORD
```

Создать базу `practica` в PostgreSQL (например, через pgAdmin или `createdb practica`), затем:

```bash
python manage.py migrate
python manage.py seed          # типы, 17 велосипедов, 25 клиентов, 16 прокатов (прокаты пересоздаются!)
python manage.py seed_users    # демо-пользователи всех ролей
python manage.py runserver
```

Приложение откроется на http://127.0.0.1:8000.

### Демо-пользователи

| Логин | Роль |
|---|---|
| `visitor` | Посетитель |
| `client` | Клиент |
| `manager` | Менеджер |
| `admin_demo` | Администратор (+ доступ в Django-админку) |

Пароль у всех один — значение `DEFAULT_PASSWORD` в `accounts/management/commands/seed_users.py`
(задать свой: `python manage.py seed_users --password <пароль>`). Пользователь, созданный через
`createsuperuser`, тоже считается администратором.

### Тесты

```bash
python manage.py test
```

## Роли и функции

| Функция | Посетитель | Клиент | Менеджер | Администратор |
|---|:---:|:---:|:---:|:---:|
| Просмотр каталога | ✓ | ✓ | ✓ | ✓ |
| Поиск, фильтры, сортировка | | ✓ | ✓ | ✓ |
| Оформление проката | | на себя | на клиента | на клиента |
| Просмотр прокатов | | свои | все | все |
| Завершение проката | | | ✓ | ✓ |
| Добавление и редактирование велосипедов | | | | ✓ |
| Добавление и редактирование клиентов | | | | ✓ |
| Редактирование записей о прокате | | | | ✓ |

Без входа пользователь — посетитель. Функции, недоступные роли, не показываются в меню; при попытке открыть
их по адресу выводится страница 403 с объяснением, а неавторизованный пользователь отправляется на вход.

## Разделы

| Адрес | Раздел |
|---|---|
| `/accounts/login/`, `/accounts/register/` | вход по логину, регистрация клиента |
| `/catalog/` | каталог: модель, тип, стоимость, доступность |
| `/catalog/<id>/` | карточка велосипеда |
| `/rentals/create/` | оформление проката с предварительным расчётом стоимости |
| `/rentals/` | мои / все прокаты с фильтром по статусу |
| `/rentals/<id>/` | прокат: клиент, велосипед, период, стоимость, статус |
| `/rentals/<id>/complete/` | завершение проката (с подтверждением) |
| `/catalog/add/`, `/catalog/<id>/edit/` | велосипеды (администратор) |
| `/rentals/clients/` | клиенты (администратор) |
| `/rentals/<id>/edit/` | редактирование проката (администратор) |

## Проверки при оформлении проката

* без выбранного клиента (для менеджера) или велосипеда прокат не оформляется;
* в списке только доступные велосипеды; подставить занятый велосипед в запрос нельзя — форма отклонит его;
* окончание проката должно быть позже начала;
* велосипед нельзя забронировать на период, пересекающийся с другим активным прокатом;
* при одновременном оформлении одного велосипеда строка велосипеда блокируется (`select_for_update`),
  второй запрос получит сообщение «велосипед только что стал недоступен».

Алгоритм расчёта стоимости — [docs/cost-algorithm.md](docs/cost-algorithm.md).

## Структура

rentals/    клиенты и прокаты, формы, сервисы оформления и завершения
