## Правила отмены

- Отменить можно только **активный** прокат. Завершённый — нельзя: выводится сообщение «Завершённый прокат отменить нельзя». Повторная отмена тоже запрещена.
- Прокат **не удаляется** из базы данных, у него меняется только статус на «Отменён». Отменённые прокаты видны во вкладке «Отменённые».
- После отмены велосипед получает статус «Доступен» и снова появляется в списке для нового проката.
- Перед отменой показывается страница подтверждения с данными проката. Без нажатия «Да, отменить прокат» ничего не меняется.
- После отмены пользователь возвращается на карточку проката с сообщением об успехе; статус обновлён в интерфейсе и в БД.

## Права доступа

| Роль | Отмена проката |
|---|---|
| Посетитель | Нет (страница 403 с сообщением) |
| Клиент | Только своего активного проката; чужой прокат ему не виден (404) |
| Менеджер | Любого активного проката |
| Администратор | Любого активного проката |

Разграничение доступа к функциям менеджера (завершение проката, все прокаты) и администратора (редактирование велосипедов, клиентов, прокатов) осталось как на этапе 2 и проверяется тестами.
